# Mission: Linux for application support

## Why

You are about to support applications on Linux servers, and you already do that work on Windows Server. You want the training shaped like MCSE: a professional, objective-based engineering course. The current equivalent is Red Hat's path. RHCSA (EX200, based on Red Hat Enterprise Linux 10) comes first. Red Hat Certified Engineer in Enterprise Linux comes after it, and requires EX342, the diagnostics and troubleshooting exam.

## Success looks like

- Check a service on a Linux server, read its journal, and say whether it is running, stopped, or failed.
- Perform the published EX200 tasks without notes, using Windows Server as the map for each new command.
- After those tasks are solid, diagnose a sick application and the system under it the way EX342 describes.

## Constraints

- Very experienced with Windows Server. Little Linux experience.
- The new job's distribution is not confirmed. Lessons follow RHEL 10, because EX200 does. systemd commands also apply on other systemd servers.
- A paid exam date is not set. The course still follows the published objectives.
- Lessons stay short. One skill at a time.

## Out of scope

- Kafka. That is a separate workspace.
- Writing the applications you support.
- The Ansible engineer exam (EX294), until you ask for it.
- Desktop Linux.
