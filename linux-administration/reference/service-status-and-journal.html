Service status and journal

Windows Server map for one application. Replace name with the unit name.

Commands

WindowsLinuxWhat you learn
Services, Status column systemctl status name Active line, plus about 10 recent journal lines.
Event Viewer for that app journalctl -u name -n 50 --no-pager Recent journal entries for that unit only.
Startup type Automatic Loaded line says enabled Boot will try to start it. This is not “running.”
Status Running Active line says active This run is up.
Status Stopped Active line says inactive This run is not up.
Stopped after a fault Active line says failed Crash, error exit, or timeout. Read the journal for the cause.

Access

The system journal is readable by root and by members of systemd-journal, adm, and wheel. Source: journalctl(1).

Earlier boots are not in systemctl status. Use journalctl -u name. Source: systemctl(1).
