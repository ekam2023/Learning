# Windows Server experience, little Linux

The user is very experienced with Windows Server and is not experienced with Linux. Future sessions should map Linux administration onto Windows Server tasks they already know, and should not reteach operating-system basics such as users, services, disks, networking, or logs as if those ideas were new.

## Evidence

Stated directly: "I am very experienced with windows server but not Linux. I need to learn more about it." Depth claimed on Windows Server is high. Depth claimed on Linux is none.

## Implications

- Teach by translation: Windows concept first, Linux equivalent second.
- Do not assume a distro, a job task, or a certification target. Those are still unknown, so `MISSION.md` stays unwritten.
